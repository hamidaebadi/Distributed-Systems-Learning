# 📚 Distributed Systems Learning Journey

This repository documents my journey to deeply understand **Distributed Systems Design, Reliability, and Security**.

The goal is not only to learn concepts, but to:
- build **strong system design intuition**
- understand **real-world distributed systems**
- implement **core algorithms from scratch**
- create a **long-term portfolio of knowledge and projects**

---

# 🎯 Objectives

- Understand the **fundamental principles** of distributed systems
- Analyze **trade-offs** in real-world system design
- Study **foundational research papers** (Raft, Paxos, Dynamo, etc.)
- Build **distributed systems projects**
- Document everything clearly with **notes and articles**

---

# 🧠 Learning Approach

Instead of passive studying, I follow a **question-driven approach**:

1. Start with **key questions**
2. Explore multiple sources (papers, books, blogs)
3. Write answers in **my own words**
4. Refine understanding through **experiments and projects**
5. Convert insights into **well-structured articles**
